# 📏 UnitConverter

A lightweight and responsive **Unit Conversion Application** built using **Java and Android XML**. UnitConverter allows users to quickly convert values across common physical measurements such as Length, Weight, and Temperature with real-time dynamic dropdown updating.

## ✨ Features

* 🔄 Dynamic Category Switcher (Length, Weight, Temperature)
* 📐 Automated Unit Dropdown Updates based on selected Category
* 🔢 Decimal Value Validation & Error Prevention
* 🎯 Output Precision Formatted to 2 Decimal Places
* 📱 Clean Vertical UI Layout using Android XML
* ⚙️ Offline Processing (No internet permission required)

## 🛠️ Built With

* Java (JDK 17)
* Android SDK (API 21+)
* Android XML Layouts
* Android Studio IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in **Android Studio**.
3. Let Gradle sync complete automatically.
4. Run the project on an **Android Emulator** or physical device.
